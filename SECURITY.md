# Security Policy

Please do not report security issues through public GitHub issues.

Report vulnerabilities to: <security@modastera.com>

Target response time:

- Initial acknowledgment: within 72 hours
- Status update after triage: within 7 days

High-priority issues for Zentra include:

- Any path that sends data off-device without explicit user action
- Permission bypasses
- Data exposure across apps or users on the same device
- Integrity issues in export or delete-all-data flows

Please include:

- A clear description of the issue
- Steps to reproduce
- Affected platform and version
- Proof of concept if available
