# Roadmap

## Milestone A

Safe public open source release and first downloadable Android APK.

Included:

- Repository sanitization
- GPL-3.0 licensing and DCO workflow
- Public README and contribution docs
- Privacy and no-network guardrails
- CI for lint, typecheck, and privacy checks
- Tagged Android release artifact

## Milestone B

Trust hardening and broader distribution.

Included:

- Reproducible build verification
- F-Droid packaging
- Additional release automation
- Expanded privacy audit surface

## Explicitly out of scope for initial release

- Cloud sync
- Accounts
- Analytics or telemetry
- Notifications, streaks, gamification
- App Store launch claims before the workflow exists
- Reproducible-build claims before verification exists
